# ¡Dilo o dibújalo! — Android

Juego de tarjetas por equipos que funciona completamente sin conexión.

## Tarjetas

La APK incluye el mazo original. Desde la pantalla inicial se puede importar un
archivo `tarjetas_actualizacion.txt`. La aplicación valida el formato, avisa de
las tarjetas añadidas y retiradas y guarda la actualización en el teléfono.

## Crear la APK con GitHub

Al subir este proyecto a un repositorio de GitHub, la acción **Crear APK** genera
automáticamente un instalador descargable desde la pestaña **Actions**.
